# Todo App

## Overview

A simple full-stack Todo application with CRUD functionality.

## Features

* Add, view, update, delete tasks
* Mark tasks as completed
* Basic validation and error handling

## Tech Stack

* React.js
* Node.js, Express.js
* MongoDB

## Setup

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## API

* GET /api/tasks
* POST /api/tasks
* PUT /api/tasks/:id
* DELETE /api/tasks/:id
